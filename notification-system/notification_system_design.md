# Campus Notifications Dashboard

## Features

- Fetch notifications from API
- Priority Inbox
- Filter by notification type
- Read/Unread notifications
- Pagination

## Priority Logic

Placement = 3
Result = 2
Event = 1

Notifications are sorted by priority score.

## Logging Strategy

Logs are generated for:
- Page loads
- API requests
- Filter changes
- Errors

- React
